============================================
   ContextBridge Chrome Extension v1.0.1
============================================

INSTALLATION INSTRUCTIONS
-------------------------

WINDOWS:
  1. Extract this zip file
  2. Double-click "install.bat"
  3. Follow the on-screen instructions

macOS:
  1. Extract this zip file
  2. Open Terminal
  3. Navigate to the extracted folder:
     cd ~/Downloads/contextbridge-chrome-v1.0.2
  4. Make the script executable:
     chmod +x install-mac.sh
  5. Run the installer:
     ./install-mac.sh
  6. Follow the on-screen instructions

MANUAL INSTALLATION (any OS):
  1. Extract this zip file to a permanent location
  2. Open Chrome and go to: chrome://extensions/
  3. Enable "Developer mode" (top-right toggle)
  4. Click "Load unpacked" (top-left)
  5. Select the extracted folder
  6. Pin the extension for easy access

CONFIGURATION:
  1. Right-click the ContextBridge icon
  2. Click "Options"
  3. Verify backend URL is: https://api.ctxbridge.io
  4. Click "Test Connection" to verify

USAGE:
  1. Open Claude.ai or ChatGPT
  2. Click the ContextBridge extension icon
  3. Start capturing your conversations!

SUPPORT:
  If you encounter issues, please contact support.
