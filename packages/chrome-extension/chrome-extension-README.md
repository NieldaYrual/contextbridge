# ContextBridge Chrome Extension

> **Capture and inject context for AI conversations across Claude, ChatGPT, and more.**

## Overview

ContextBridge enables seamless knowledge management across your AI conversations. Capture conversations from multiple platforms, build a searchable knowledge base, and inject relevant context into new conversations.

## Features

- 🔄 **Multi-Platform Support**: Works with Claude.ai and ChatGPT (more coming soon)
- 📥 **Automatic Capture**: One-click capture of entire project conversations
- 🔍 **Intelligent Search**: Semantic search across your conversation history
- 💉 **Context Injection**: Insert relevant context directly into your AI chats
- 🔐 **Data Ownership**: Your data stays under your control

## Installation

1. Download the extension from the Chrome Web Store (coming soon)
2. Or load unpacked from the `packages/chrome-extension` directory for development

## Usage

1. Navigate to a Claude.ai or ChatGPT project page
2. Click the ContextBridge extension icon to capture conversations
3. Use the floating search button (🔍) to find and inject relevant context

## Requirements

- Google Chrome or Chromium-based browser
- Active ContextBridge account (for cloud sync features)
