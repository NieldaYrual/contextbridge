Install VS Code Extension

Sync your code context with ContextBridge

Download Extension

contextbridge-codex-0.0.1.vsix

Open VS Code

Launch Visual Studio Code on your computer.

Open Extensions Panel

Press Ctrl+Shift+X or click the Extensions icon in the sidebar.

Install from VSIX

Click the ··· menu at the top of the Extensions panel, then select Install from VSIX...

Select the Downloaded File

Navigate to your Downloads folder and select contextbridge-codex-0.0.1.vsix

Configure & Sync

Press Ctrl+Shift+P and type ContextBridge: Sign In to connect your account, then select a project to start syncing.
