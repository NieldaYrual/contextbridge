Connect your tools

ContextBridge syncs your code, repos, and conversations so your AI always has the full picture.

Install for VS Code Install for Cursor Connect GitHub
VS Code & Cursor — 4 quick steps to start syncing
  1. Sign in. Open the Command Palette (Ctrl+Shift+P on Windows/Linux, Cmd+Shift+P on Mac), search for ContextBridge: Sign In, and enter the email and password from your ContextBridge account.
  2. Select your projects. Open the Command Palette again, search ContextBridge: Select Project, and pick which ContextBridge projects to sync your code into.
  3. Sync your workspace. Run ContextBridge: Sync Entire Workspace from the Command Palette to do an initial full sync.
  4. You're done. From now on, file changes sync automatically. Your code is available to any AI chat that uses ContextBridge.
GitHub — 3 quick steps to connect your repo
  1. Install the GitHub App. Click "Connect GitHub" above. Choose which repositories to grant access to, then click Install.
  2. Complete the setup. After installing, you'll be redirected to ContextBridge to link the installation to your account. You'll need the ContextBridge Chrome extension installed and signed in.
  3. You're done. Your repo is synced. Every push to the tracked branch automatically updates your ContextBridge knowledge base.
